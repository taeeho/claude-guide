PART 1 · DESKTOP

Claude APP 설치

브라우저 없이 데스크톱에서 바로 Claude와 대화할 수 있는 공식 앱입니다. claude.com/download 에서 받습니다.

Windows 설치 순서
1

다운로드 페이지 열기

claude.com/download 접속 → 상단의 “Download for Windows” 버튼 클릭.

※ ARM 노트북(Surface 등) 사용자는 옆의 Windows (arm64) 버튼을 누르세요.

2

.exe 설치 파일 실행

다운로드 폴더에서 받은 파일을 더블클릭합니다.

3

설치 마법사 진행

Next → Install → Finish 순서로 기본값 그대로 진행하면 됩니다.

4

실행 후 로그인

설치가 끝나면 자동으로 Claude가 실행됩니다. Anthropic 계정(또는 Google)으로 로그인하면 끝.

i 회사 계정으로 사용하시는 분은 ai@ccfm.co.kr 도메인 계정으로 로그인해주세요.
macOS 설치 순서
1

다운로드 페이지에서 macOS 선택

claude.com/download 의 Get started → Desktop → macOS 의 Download 버튼을 누릅니다.

2

.dmg 파일 다운로드

받은 디스크 이미지를 더블클릭해서 엽니다.

3

Applications 폴더로 드래그

Claude 아이콘을 옆의 Applications 폴더로 끌어다 놓으면 설치가 끝납니다.

4

실행 → 보안 경고 시 “열기” 클릭

처음 실행할 땐 macOS 보안 경고가 한 번 뜹니다. “열기”를 누르고 Anthropic 계정으로 로그인.

PART 2 · CLI

Claude Code 설치

터미널에서 Claude를 코딩 파트너로 부리는 CLI 도구입니다. 설치 후엔 폴더로 들어가 claude 한 줄이면 바로 시작돼요. Pro / Max / Team / Enterprise 요금제 계정이 필요합니다.

Windows · PowerShell 기준
1

PowerShell 열기

시작 키 → “PowerShell” 입력 후 엔터.

! PowerShell 이어야 합니다. CMD(명령 프롬프트) 아닙니다.

먼저 Git이 깔려있는지 확인합니다:

PS>git -v

버전이 출력되면 3단계로 건너뛰기, 안 나오면 2단계부터 진행하세요.

2

Git 설치 (필요한 경우만)

git-scm.com/install/windows 에서 “Click here to download”를 누르고 받은 설치파일을 실행합니다.

설치 마법사의 모든 옵션은 전부 Default 그대로 두고 Next → Finish 까지 진행하면 됩니다.

3

Claude Code 설치 명령어 실행

PowerShell에 아래 한 줄을 붙여넣고 엔터:

PS>irm https://claude.ai/install.ps1 | iex
4

새 PowerShell 창 열기

기존 창을 닫고 새 PowerShell을 다시 엽니다. PATH 환경변수가 새 창부터 적용되기 때문에 이 단계를 거르면 다음 명령이 인식되지 않아요.

5

설치 확인 & 실행

PS>claude -v

버전이 뜨면 성공. 작업할 폴더로 이동해서 실행합니다:

PS>cd C:\작업할폴더경로
PS>claude
  • 첫 실행 시 브라우저가 자동으로 열려 Anthropic 로그인 화면이 나옵니다.
  • 로그인이 끝나면 PowerShell로 돌아와서 바로 사용 가능.
macOS · Terminal 기준
1

터미널 열기

⌘ + Space → "terminal" 입력 → 엔터.

2

설치 명령어 실행

터미널에 아래 한 줄을 붙여넣고 엔터:

$curl -fsSL https://claude.ai/install.sh | bash
3

새 터미널 창 열기

설치 후엔 반드시 새 창을 열어야 claude 명령이 인식됩니다 (PATH 반영).

  • ⌘ + N 또는 터미널 재시작
4

설치 확인

$claude -v

버전이 뜨면 성공.

5

실행

$cd ~/작업할폴더경로
$claude
  • 첫 실행 시 브라우저가 자동으로 열립니다.
  • Anthropic 계정으로 로그인 (Pro / Max / Team / Enterprise 필수).
  • 로그인이 끝나면 터미널로 돌아와서 바로 사용 가능.
PART 3 · EXTENSIONS

MCP 서버 추천 9선

MCP(Model Context Protocol)는 Claude가 외부 도구·데이터와 연결되는 통로예요. 설치해두면 Claude가 브라우저를 켜고, 노션을 읽고, 최신 문서를 찾아올 수 있어요. AX기획팀 업무 흐름에 특히 궁합이 좋은 9개를 골라봤어요.

설치 방법 (Claude Code 기준) — 아래 각 카드의 명령을 터미널에 그대로 붙여넣으면 됩니다.
등록 후에는 claude mcp list 로 연결 상태를 확인할 수 있어요.
데스크톱 앱에서 쓰려면 Settings → Connectors → MCP Servers 에서 동일한 커맨드를 JSON으로 등록.
$claude mcp list
$claude mcp add <name> -- <command> <args...>
PW
필수

Playwright

실제 브라우저를 열어 웹 동작·E2E 시나리오를 검증.

  • 내가 만든 MVP 화면이 실제로 동작하는지 확인
  • 로그인·폼·스크린샷 자동화
  • 바이브코딩 결과물 회귀 테스트
$claude mcp add playwright -- npx -y @playwright/mcp@latest
공식 문서 → Node.js 필요
C7
필수

Context7

라이브러리·프레임워크 최신 공식 문서를 실시간으로 주입.

  • React / FastAPI / Supabase SDK 버전 따라가기
  • 학습 데이터보다 최신인 API 반영
  • “이 버전엔 이 메서드 없어요” 방지
$claude mcp add context7 -- npx -y @upstash/context7-mcp
공식 문서 → API key 선택
ST
필수

Sequential Thinking

복잡한 문제를 단계별로 쪼개서 깊게 사고하게 만드는 추론 도구.

  • 아키텍처 / 트레이드오프 판단
  • N8N vs 코드 구현 같은 선택지 비교
  • 디버깅 가설 트리 탐색
$claude mcp add sequential-thinking -- npx -y @modelcontextprotocol/server-sequential-thinking
공식 문서 → 키 불필요
No
필수

Notion

Notion 페이지·DB를 직접 읽고 쓰며 문서화 자동화.

  • 회의록·가이드·요구사항 페이지 자동 생성
  • 팀 위키 검색·요약
  • 업무 티켓 DB CRUD
$claude mcp add notion \
  --env NOTION_TOKEN=secret_xxx -- \
  npx -y @notionhq/notion-mcp-server
공식 문서 → Internal Integration 토큰 필요
GD
필수

Google Drive

드라이브 파일 검색·읽기·Google Sheets 내용 접근.

  • 팀 드라이브의 자료 검색·요약
  • Sheets 데이터 불러와 분석·리포트 생성
  • 첨부 PDF·문서 맥락으로 사용
$claude mcp add gdrive -- npx -y @modelcontextprotocol/server-gdrive
공식 문서 → OAuth 인증 필요
GC
업무

Google Calendar

일정 조회·생성·리마인더 자동화.

  • "다음주 회의 잡아줘" 처럼 자연어로 일정 등록
  • 회의 전 브리핑 노트 자동 생성
  • 빈 시간 탐색 후 일정 제안
$claude mcp add gcal -- npx -y @cocal/google-calendar-mcp
공식 문서 → OAuth 인증 필요
Sb
업무

Supabase

PostgreSQL 쿼리·스키마 관리·스토리지를 Claude가 직접.

  • AX팀 기본 DB 스택과 궁합 최상
  • 테이블 설계·마이그레이션 초안
  • 데이터 추출·리포트 쿼리 자동화
$claude mcp add supabase \
  --env SUPABASE_ACCESS_TOKEN=sbp_xxx -- \
  npx -y @supabase/mcp-server-supabase@latest
공식 문서 → Access Token 필요
Fs
업무

Filesystem

허용한 폴더만 안전하게 읽기/쓰기 — 데스크톱 앱에서 특히 유용.

  • Claude 앱이 로컬 파일을 직접 다룰 수 있게
  • 여러 프로젝트 폴더 넘나들기
  • 권한 범위 명시적 제한(보안↑)
$claude mcp add fs -- \
  npx -y @modelcontextprotocol/server-filesystem \
  "C:\Users\MKM10011\Desktop"
공식 문서 → 허용 경로 지정
Gh
업무

GitHub

저장소·이슈·PR·코드 검색을 Claude가 직접 다루기.

  • PR 리뷰·요약·코멘트
  • 이슈 티켓 자동 생성
  • 레포 코드 검색 후 수정 제안
$claude mcp add --transport http \
  github https://api.githubcopilot.com/mcp/
공식 문서 → GitHub OAuth 필요
i 커맨드가 잘 안 먹히면 claude mcp remove <name> 로 지우고 다시 등록하세요. Node.js 기반 MCP는 최초 실행 시 npx가 패키지를 받느라 몇 초~수십 초 걸릴 수 있어요.
PART 4 · CHECKLIST

안 될 때 확인할 것

설치 중 가장 자주 막히는 지점을 모았어요. 위에서 아래로 한 번씩 점검해보세요.

!

claude 명령어가 인식되지 않아요

거의 100% 새 터미널 창을 안 열어서 생기는 문제입니다. 기존 창을 완전히 닫고 새 PowerShell / Terminal을 열어 다시 시도하세요.

!

Windows에서 git이 안 잡혀요

Git 설치 후에도 같은 PowerShell 창에서는 인식되지 않습니다. 새 창을 열고 git -v 를 다시 확인하세요.

!

로그인 후에도 “요금제 필요” 메시지가 떠요

Claude Code는 무료 계정으로는 사용할 수 없습니다. Pro / Max / Team / Enterprise 요금제 계정인지 확인해주세요.

!

macOS에서 “확인되지 않은 개발자” 경고

처음 한 번만 나옵니다. 시스템 설정 → 개인정보 보호 및 보안에서 “그래도 열기”를 누르거나, 처음 실행 시 보안창의 “열기” 버튼을 클릭하세요.
